# 빈틈없이

[게임 실행](https://kkankong32-alt.github.io/binteumeopsi/)

기획·제작 © 2026 쓰로인훈쌤 김종훈 · 초등 수업을 위한 무료 교육 콘텐츠

## 개발

Node.js 24에서 `npm ci`, `npm run dev`로 실행합니다. `npm test`는 단위 테스트, `npm run build`는 정적 실행본을 만듭니다.

GitHub Actions가 main 브랜치에서 빌드 후 Pages에 배포합니다. 이 저장소에는 게임 소스·런타임 에셋·검증 소스만 포함합니다. 공식 사용설명서 PDF, 교과서 원본, 개인 작품, 대용량 QA 캡처와 계정 인증정보는 포함하지 않습니다. 공개 게임에서는 PDF 링크를 표시하지 않습니다.

## 방문통계와 저장

운영 주소에서 사용자가 방문통계를 허용한 경우에만 Google tag를 불러옵니다. 로컬·개발 환경에서는 비활성입니다. 화면 이름만 허용 목록으로 전달하며 작품 제목·이름·작품 JSON은 전달하지 않습니다. 통계 거부 시에도 게임 기능은 동일합니다. 분석 쿠키와 브라우저/기기 정보가 사용되고 Google 연결 시 IP 주소가 전달될 수 있습니다. 광고 개인화는 사용하지 않습니다.

자동저장은 현재 기기·브라우저에만 남습니다. 다른 주소·브라우저·기기로 옮길 때는 프로젝트 JSON을 저장하고 다시 불러오세요.
